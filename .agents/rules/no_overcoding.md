# STRICT DEVELOPMENT RULES: NO OVER-CODING & STRICT SCOPE ADHERENCE

## Core Rules:
1. **Implement ONLY What Is Explicitly Requested:**
   - If asked for a component or file, create ONLY that component/file.
   - Do NOT add unrequested text, extra mockups, or unprompted elements.

2. **NO Unnecessary Terminal Commands / Builds:**
   - The dev server (`npm run dev`) is already running. 
   - **NEVER** run `npm run build` or unnecessary build commands in the background unless the user explicitly requests a production build.

3. **Strict Scope Control:**
   - Keep skeleton/wireframe components completely empty unless requested otherwise.
   - Wait for explicit instructions before modifying other files.
