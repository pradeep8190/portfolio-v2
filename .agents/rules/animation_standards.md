# ANIMATION & CODE QUALITY STANDARDS: NO SHORTCUTS & FULL FIDELITY

## Core Rules:
1. **Never Take Shortcuts on Premium Animations:**
   - Do NOT attempt to reduce complex, ultra-premium animations to basic 50–100 line CSS transform shortcuts.
   - When the user asks for satisfying, high-fidelity, or Apple-level visual effects, write the proper code from the beginning (e.g. custom WebGL shaders, per-pixel GPU calculations, mathematical easing).
   - Do not rush or be lazy—engineer the real graphics solution directly.

2. **Full Image Visibility (Zero Cropping):**
   - Never crop, zoom in, or cut off UI screenshots and portfolio images.
   - Always ensure the entire image is 100% visible with proper aspect-ratio containment.

3. **Avoid Cheap Design Gimmicks & Blocky Pixel Noise:**
   - Do NOT add fake browser bars (colored dots, emoji locks, fake URL pills) or arbitrary colored border outlines unless explicitly requested.
   - Avoid retro chunky square pixel noise or blinding white flashbangs unless specifically asked; use continuous optical fluid waves, spectral refraction, and smooth bokeh blur.
   - Adhere strictly to spacing requirements (e.g. edge-to-edge full width with zero gaps and zero jitter).
